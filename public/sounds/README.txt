Place your notification audio file here with the exact filename:

  msn-wizz-sound.mp3

The app will attempt to play `./sounds/msn-wizz-sound.mp3` when a new suporte arrives. If the file is absent or playback fails, the app falls back to a built-in oscillator sound.

To add the file:
- Copy the MP3 you attached into this folder and rename it to `msn-wizz-sound.mp3`.
- Or run (from project root):

  cp /path/to/your/msn-wizz-sound.mp3 public/sounds/msn-wizz-sound.mp3

After placing the file, reload the web page.
